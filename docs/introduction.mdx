# Welcome to Posthoot API

Posthoot is a robust Go-based backend service for email campaign management with advanced authentication and permission systems. This API provides comprehensive functionality for managing email campaigns, analytics, user management, and more.

## 🚀 Key Features

### 🔐 Authentication System
- JWT-based authentication with refresh tokens
- Role-based access control (RBAC)
- Password reset functionality with time-limited codes
- Support for API keys with granular permissions
- Google OAuth integration

### 📊 Analytics & Tracking
- Comprehensive email analytics
- Click and open tracking
- Audience insights and segmentation
- Campaign performance metrics
- Geographic and device analytics

### 🎯 Campaign Management
- Create, read, update, delete campaigns
- Campaign scheduling and automation
- Template management
- Contact list management

### 💳 Subscription System
- Integration with Dodo Payments
- Feature-based access control
- Subscription management portal
- Webhook support for payment events

## 🛠️ Technology Stack

- **Backend**: Go 1.21+
- **Database**: PostgreSQL 14+
- **Cache**: Redis
- **Authentication**: JWT + Firebase
- **Payments**: Dodo Payments
- **Documentation**: Swagger/OpenAPI

## 🔗 Base URL

```
https://api.posthoot.com
```

## 📋 Prerequisites

- Go 1.21 or higher
- PostgreSQL 14 or higher
- Redis (for rate limiting and caching)

## 🚀 Quick Start

1. **Register a new account**
   ```bash
   curl -X POST https://api.posthoot.com/auth/register \
     -H "Content-Type: application/json" \
     -d '{
       "email": "user@example.com",
       "password": "secure_password",
       "first_name": "John",
       "last_name": "Doe"
     }'
   ```

2. **Login to get access token**
   ```bash
   curl -X POST https://api.posthoot.com/auth/login \
     -H "Content-Type: application/json" \
     -d '{
       "email": "user@example.com",
       "password": "secure_password"
     }'
   ```

3. **Use the API with your token**
   ```bash
   curl -X GET https://api.posthoot.com/auth/me \
     -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
   ```
