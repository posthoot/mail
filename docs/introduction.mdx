# Welcome to Posthoot API

Posthoot is an **open-source email marketing engine** that gives you complete control over your email infrastructure. Built with Go and designed for scale, Posthoot connects to multiple SMTP providers, provides advanced template management, brings AI into your workflows, and enables marketing campaigns to run on autopilot.

## 🎯 What is Posthoot?

Posthoot is more than just an email API - it's a complete email marketing platform that you control. Unlike traditional email services that lock you into their ecosystem, Posthoot is:

- **🔓 Open Source**: Full transparency and complete customization
- **🔌 Multi-Provider**: Connect to any SMTP provider (SendGrid, Mailgun, Amazon SES, etc.)
- **🤖 AI-Powered**: Intelligent automation and optimization
- **🚀 Self-Hosted**: Complete control over your data and infrastructure
- **💰 Cost-Effective**: No vendor lock-in or hidden fees

## 🛠️ Technology Stack

### Backend & Infrastructure
- **Backend**: Go 1.21+ (high-performance, concurrent)
- **Database**: PostgreSQL 14+ (reliable, ACID-compliant)
- **Cache**: Redis (fast, distributed caching)
- **Queue System**: Redis-based job queues for email processing
- **File Storage**: Local storage with cloud provider support

### Authentication & Security
- **Authentication**: JWT + Firebase OAuth
- **Rate Limiting**: Redis-based distributed rate limiting
- **Encryption**: TLS/SSL for all communications
- **API Security**: CORS protection and secure headers

### Email Infrastructure
- **SMTP Providers**: Multi-provider support (SendGrid, Mailgun, Amazon SES, etc.)
- **Email Processing**: Asynchronous email processing with retry logic
- **Tracking**: Pixel-based open tracking and link click tracking
- **Bounce Handling**: Automatic bounce processing and list cleaning

### Development & Documentation
- **API Documentation**: Swagger/OpenAPI 3.0
- **Testing**: Comprehensive test suite with Go testing
- **CI/CD**: GitHub Actions for automated testing and deployment
- **Monitoring**: Built-in logging and metrics collection

## 📋 Prerequisites

### For API Usage
- **API Access**: Valid Posthoot account and API credentials
- **HTTP Client**: Any HTTP client (curl, Postman, SDK, etc.)
- **Authentication**: JWT token for authenticated endpoints

### For Self-Hosting
- **Go**: 1.21 or higher
- **PostgreSQL**: 14 or higher
- **Redis**: 6.0 or higher (for rate limiting and caching)
- **Docker**: Optional, for containerized deployment
- **SMTP Provider**: At least one SMTP provider configured

## 🚀 Quick Start

### 1. Create Your First Campaign

```bash
# Register a new account
curl -X POST https://api.posthoot.com/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "secure_password",
    "first_name": "John",
    "last_name": "Doe"
  }'

# Login to get access token
curl -X POST https://api.posthoot.com/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "secure_password"
  }'
```

### 2. Configure SMTP Provider

```bash
# Add your SMTP provider
curl -X POST https://api.posthoot.com/smtp \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "SendGrid",
    "host": "smtp.sendgrid.net",
    "port": 587,
    "username": "apikey",
    "password": "YOUR_SENDGRID_API_KEY"
  }'
```

### 3. Send Your First Email

```bash
# Send a test email
curl -X POST https://api.posthoot.com/email \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "recipient@example.com",
    "subject": "Welcome to Posthoot!",
    "html": "<h1>Hello from Posthoot!</h1><p>This is your first email.</p>",
    "from": "sender@yourdomain.com"
  }'
```

### 4. Check Analytics

```bash
# Get email analytics
curl -X GET https://api.posthoot.com/analytics/email \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```
