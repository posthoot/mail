# API Reference

Welcome to the Posthoot API reference. This is your complete guide to integrating with our email automation and analytics platform.

## Quick Start

The Posthoot API is RESTful and follows standard HTTP conventions. All requests should be made to `https://api.posthoot.com` and include proper authentication headers.

```bash
curl -X GET "https://api.posthoot.com/api/v1/users/me" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

## Authentication

Most API endpoints require authentication. You can authenticate using:

- **Bearer Token**: Include your API key in the Authorization header
- **JWT Token**: For user-specific operations

```bash
# Using API Key
Authorization: Bearer pk_live_your_api_key_here

# Using JWT Token  
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

## Base URL

```
https://api.posthoot.com
```

## API Versioning

The API is versioned using the URL path. Currently, we support:

- **v1**: Current stable version (recommended)

```
https://api.posthoot.com/api/v1/
```

## Response Format

All API responses are returned in JSON format with the following structure:

```json
{
  "data": {
    // Response data here
  },
  "message": "Success message",
  "status": "success"
}
```

## Error Handling

Errors follow a consistent format:

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid request parameters",
    "details": {
      "field": "email",
      "issue": "Email format is invalid"
    }
  },
  "status": "error"
}
```

## Rate Limiting

API requests are rate-limited to ensure fair usage:

- **Authentication endpoints**: 5 requests per minute
- **API endpoints**: 100 requests per minute
- **File uploads**: 10 requests per minute

Rate limit headers are included in all responses:

```
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1640995200
```

## SDKs & Libraries

We provide official SDKs for popular languages:

- **Node.js**: `npm install @posthoot/sdk`
- **Python**: `pip install posthoot-sdk`
- **Go**: `go get github.com/posthoot/go-sdk`
- **PHP**: `composer require posthoot/php-sdk`

## Webhooks

Configure webhooks to receive real-time notifications:

- **Email Events**: Opens, clicks, bounces, complaints
- **Campaign Events**: Started, completed, paused
- **Subscription Events**: Created, updated, cancelled
